# Contributing to J1 Code

Bug reports and proposals are welcome. Search this repository's issues first, then explain the problem and how to reproduce it. For a larger feature, open an issue to discuss the scope before implementing it. New code or documentation contributions require a separate agreement identifying the contributor's rights and intended permissions before acceptance; submission alone does not transfer copyright.

Start with the [development runbook](docs/operations/development.md) and [project instructions](AGENTS.md). Use isolated development state and preserve existing user data. Run focused tests, lint, and typechecks for the code you change.

Keep pull requests focused on one concern. Describe the resulting behavior and checks you ran. Include before/after images for UI changes, or a short recording when timing matters. Do not commit credentials, user profiles, transcripts, personal memory exports, or review-only screenshots.

J1 Code is maintained independently of [T3 Code](https://github.com/pingdotgg/t3code). Report J1-specific issues here; upstream contributions follow T3 Code's own contribution policy. Preserve upstream MIT notices, component licenses, and existing grants. New protected J1 work follows [the current licensing boundaries](LICENSING.md); public visibility does not grant a general reuse license.
