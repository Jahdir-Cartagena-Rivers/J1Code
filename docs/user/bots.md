# Bots

Use **Bots** above Chats to create reusable agents with their own purpose, instructions, model, and icon. A bot is standalone by default; choose a project if its work should use that project's workspace and settings. Pinning is optional.

Select a bot to reopen its latest active conversation, or start a new conversation with it. Each conversation keeps the instructions it started with; editing a bot changes future conversations. Archive a bot to hide it, then show archived bots to restore it. Existing conversations remain available.

Add routines to ask a bot to work once or at an interval. Routines run on the bot's environment when its server is running, and their history shows whether a turn was requested or could not be started. Open the routine conversation to see the work and its outcome.

On supported clients, bots can read completed replies aloud using voices installed on that device. Choose a voice and optionally enable automatic playback when editing the bot. Voice availability depends on the client device.

Start a voice call from a bot conversation to speak back and forth. The microphone closes while the bot replies; use Interrupt to speak again. Calls stop when J1 needs an approval or other input, which you can review in the conversation.

Open a bot conversation's browser to see its current background page. If it has not started yet, choose Start browser, then enter a web address. You and the bot interact with the same page; closing the window leaves its background work running. The lightweight view can look different from a full browser, and temporary sessions expire after inactivity. Tools already installed on the environment remain available through the bot's provider and its normal permissions.
